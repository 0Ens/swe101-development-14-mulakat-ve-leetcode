# Problem adı
Valid Anagram

## Yaklaşım
elimdeki stringleri bir arraye donusturup tekrardan siraladim ve bunlari string hallerini kiyasladim eger ki anagramlar ise ikiside ayni kelime olmak zorundaydi degillerse anagram degil false doner

## Zaman karmaşıklığı
O(nlogn)

## Bellek karmaşıklığı
O(n)

## Yanıldığım nokta
array halleriyle karsilastirma yapip anagrammi diye kontrol etmek istedim fakat bu haldeyken gelen her sonuc false verdi sebebiyse javascript array karsilastirmasinda icerikleri degil array karsilastiriyormus bu sebeple iki farkli array karsilastigi icin direkt false donuyor.cozumunu arrayleri siralayip string yapmakla sagladim
