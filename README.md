# swe101-development-14-mulakat-ve-leetcode

SWE-101 için LeetCode çözüm günlüğü ve STAR hikaye bankası. Her problemin kendi klasöründe çözümü, testleri ve yaklaşım + karmaşıklık notu bulunur.

## Kurulum

```bash
npm install
```

## Test

```bash
npm test
```

## Problemler

| Problem | LeetCode | Zorluk | Durum |
| --- | --- | --- | --- |
| Two Sum | [Link](https://leetcode.com/problems/two-sum/) | Easy | Accepted |
| Contains Duplicate | [Link](https://leetcode.com/problems/contains-duplicate/) | Easy | Accepted |
| Valid Anagram | [Link](https://leetcode.com/problems/valid-anagram/) | Easy | Accepted |
| Best Time to Buy and Sell Stock | [Link](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/) | Easy | Accepted |
| Valid Palindrome | [Link](https://leetcode.com/problems/valid-palindrome/) | Easy | Accepted |


## Klasör yapısı

```
problems/
  _sablon/not.md       # not şablonu
  two-sum/
    solution.js        # çözüm fonksiyonu
    solution.test.js   # LeetCode örnekleri + sınır durumları
    not.md             # yaklaşım + karmaşıklık notu
interview-prep.md      # STAR hikayeleri
```

## Ne öğrendim

- Hash map ve Set'i daha etkili kullanmayı ve nerelerde daha efektif kullanabileceğimi öğrendim.
- Bellekten verip zamandan kazanma örnekleri yaşadım. TLE'ye takılmıştım, artık daha hızlı çalışabilecek algoritmalar kurabiliyorum.
- `toString` kullanılırken dizideki her değerin arasına virgül eklendiğini öğrendim.
- Regex kullanarak sembol filtrelemeyi öğrendim.
- Bundan sonra kod yazmaya başlarken aklıma mantıklı gelen ilk fikirle değil, plan sonucu mantıklı bulduğum yolla başlayacağım.
